Onça-pintada
============

Onça-pintada calculates alloy mixing thermodynamics and generates atomistic
configurations for binary and multicomponent substitutional alloys. It includes
subregular solution models, binary pair QCA, tabulated phase boundaries,
vibrational thermodynamics, and a Calango-style Cluster Expansion builder.
